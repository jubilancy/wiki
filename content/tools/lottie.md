# **Where to Get Free Animation Files (If Needed)**

- [LottieFiles Public Discover](https://lottiefiles.com/free-animations): Searchable catalog of ready-to-use JSON and `.lottie` motion graphics with public asset URLs.
    
- [Lordicon](https://www.google.com/search?q=https%3A%2F%2Flordicon.com): Interactive animated icons available in direct JSON format.
    
- [UseAnimations](https://www.google.com/search?q=https%3A%2F%2Fuseanimations.com): Free, open-source animated UI icons and loaders formatted for Lottie.

# **Supported Export Formats Included**

- **Animated GIF:** Generates an animated multi-frame GIF directly client-side via [gifshot](https://www.google.com/search?q=https://github.com/yahoo/gifshot).
    
- **Animated SVG:** Generates a resolution-independent vector file with embedded SMIL color looping animations.
    
- **Lottie JSON:** Generates a valid [Bodymovin / Lottie specification](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2FLottieFiles%2Flottie-spec) file with keyframed fill vectors.
    
- **WebM / MP4 Video:** Records rendered canvas stream directly using the browser [MediaStream Recording API](https://www.google.com/search?q=https%3A%2F%2Fdeveloper.mozilla.org%2Fen-US%2Fdocs%2FWeb%2FAPI%2FMediaStream_Recording_API).
    
- **PNG / JPEG / WebP:** Captures instant raster snapshots directly via native Canvas Blob APIs.
